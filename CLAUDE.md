# Still Water

A short procedural pixel-art fishing horror game in one self-contained HTML file, built for mobile portrait and itch.io.

The art style follows NakoFrish's "AM: The Verdant Reach" image: a blue fjord, big pixel cumulus with bright tops, a low white sun in the centre, a mirror-still lake, and a dark boat with curled prow and stern.

Premise: it starts as a calm fishing game, and a golden fish grants three wishes. Then the sun sets and a red eye-sun rises, hanging on a line from the sky. Every sun is bait, the mountains are teeth, and the player is the fish. There are seven endings (Home, Dark, Still water, Stay, Deep, Swallowed, Inside) and a silent variant of Still water. The script and the world-state ledger are `docs/story.md`; when the code and the bible disagree, fix one the same day. The game ships in English and Russian, one page per language (see Languages).

## Working on this project
- The user plays on a phone and shares the four GitHub Pages links: `/`, `/test.html`, `/ru/`, `/ru/test.html` (https://tahiktim-coder.github.io/still-water/). Pushing to main redeploys all four, plus `/itch/`, the exact itch.io upload (`node build.js --itch`), so push each finished piece and say that you did.
- Testing is silent: the user hears anything a test plays. Launch every browser with `--mute-audio` and never an autoplay flag, and do not use an in-app browser pane. Listen to sound only by rendering it offline with `npm run sfx`.
- Look at the real screens yourself before calling UI work done: `npm run uishots`, then read the sheets in `tools/out/ui/sheets/` and `summary.txt`, in both languages and at 320, 375 and desktop widths.
- The UI direction is simple, clean and beautiful: fewer words, no decoration. The story lines are the user's; do not cut or rewrite one without asking.
- Every string the player sees needs its `RU` entry.
- Run `npm run sim`, `npm run skipcheck` and `npm run domtest` before committing.

## Commands
- `npm install`: run once. It only installs the dev tools, pngjs and jsdom.
- `npm run build`: writes `dist/index.html` by inlining `src/game.js` into `src/template.html` at `/*GAME*/`. Full-line `//` comments are dropped on the way (the source keeps them) to keep the single file small (about 290 KB with the Russian table, the title lettering and the synthesised sound; itch.io has no practical limit at this size, so this is a tidiness target, not a hard cap). Never edit `dist/` by hand.
- `npm run sim`: a headless bot plays through every ending (plans are choice indices in menu order, listed at the top of `tools/sim.js`; a `{ wait: true }` option holds the bot through the ocean window, `{ tap: true }` taps the companion once per act, a third element is a sentence the ending card must end with, `{ base: n }` the bible's situation number whose exact text the card must start with, `{ noPocket: true }` for the lake-sunk Still water card, `{ ruCard: { base, extra } }` the Russian base and extra an Inside card must carry in the Russian pass). On every let-go plan it also asserts that `WS.goldKept` stays 0 through the dialogue, so `drawKeptFish` never stamps a kept fish on a released path. It prints one `ending <id> reached` line per ending id (the seven plus `cut:silent`). Then a Russian pass plays every plan again with `LANG` = 'ru' (`setLang`): each must reach the same ending as in English, and no text the player sees (every stub UI log entry of kind caption, think, dialogue, choices, card, ending, prompt and the panel label) may contain a Latin letter; it prints `ru ending <id> reached` lines and `RUSSIAN OK`. The English pass keeps all its assertions. The run must end with `ALL ENDINGS REACHED`. Its reel bot sees the line 0.35 s late, like a person (it lets go when it sees a surge or high tension), and each run's line carries `snaps=`; the summary line gives the snaps per run and the mean run length.
- `npm run shots`: renders scene states (`tools/shot.js`, one `out_*.png` per scene, `node tools/shot.js <scene>` for one) and ending frames (`tools/snaps.js`, `e_*.png`; each capture is timed from the wish 3 choice, or from the red rise with a third element `'red'`, or from the ending cinematic's start with `'cine'`) to `tools/out/`. Look at them after any visual change.
- `node tools/cloudshots.js`: renders the sky alone to `tools/out/clouds_*.png` (day at t 0 and 40 s, night, red, and the wrap seam at 20, 60 and 133 s) and times `render()` 300 times. Use it when touching the clouds.
- `npm run domtest`: plays the built page in jsdom with the canvas stubbed (its bot reads the stage's `data-phase`, since the prompts step aside after the first catches, and checks that the first run shows the cast, wait, bite and reel prompts), then the Russian page (`tools/out/ru/index.html`, opened at its Pages address): its title, the link back to `../`, and one run with no Latin letter on screen. It is slow and takes a few minutes.
- `npm run skipcheck`: verifies the temporary test mode below: a skip is a no-op with test mode off and before the boat arrives, four skips reach the golden dialogue, a skipped run reaches the red sequence and an ending, and a skip in the ocean window casts into the big one. It takes under a second.
- `npm run sfx` (`tools/sfxrender.js`, DSP in `tools/sfxmeasure.js`): renders the sound silently. It opens the game in headless Edge or Chrome with `--mute-audio` (`--browser=<exe>` or `SFX_BROWSER` to pick one) and points the real `SFX` at an OfflineAudioContext (`window.AudioContext` is swapped while `SFX.init` builds the chain; `Math.random` is seeded, so renders repeat). Each sound, with its call sites' arguments, goes to `tools/out/sfx/sounds/` as a 44.1 kHz WAV and a log-frequency spectrogram PNG, measured for peak, true peak, RMS, loudest 400 ms in LUFS (K-weighted, as played on both channels), the same through a 250 Hz high-pass (a phone speaker), centroid, energy above 4 kHz and below 150 Hz, clipping, DC, clicks, dead stops and unlooped noise sources that run past their buffer. A lone sound plays `LEAD` (0.4 s) into its render, since a DynamicsCompressor starts clamped; it goes through the whole master chain without the bed. Every sound the game calls is in the list, with its call sites' arguments. Then it plays four runs headless in Node with human pacing (`stay`, `sea`, `swallowed`, `inside`; `--timeline=stay,sea` or `none`), each in a freshly loaded game so no state leaks from one run's ending into the next, logs every `SFX` call the game makes (not the ones a sound makes itself) with its time and replays the log offline with the ambient bed, the drone, the heartbeat and the weight into `timeline/<run>.wav`, a loudness-over-time plot, a spectrogram and the event list, and checks the red's heart (`heartCheck`: a WARNING with fewer than one beat per 6 s of drone, or two beats under 0.5 s apart). `--only=knock,hiss` renders some sounds; `--out=<dir>` writes elsewhere; `summary.json` holds every number. About a minute. Look at the PNGs after any sound change.
- `npm run uishots` (`node tools/uishots.js [outDir] [--runs=home,stay] [--sizes=375x812] [--langs=en] [--jobs=6] [--speed=3] [--no-build] [--browser=<exe>]`, default `tools/out/ui/`): the UI capture. It runs `build:site`, copies the four pages into `<outDir>/pages` with the engine exposed (a hook pasted at the end of the IIFE, a head shim that removes `AudioContext` and puts the game's `setTimeout`s on the game clock), serves them on 127.0.0.1 and drives headless Edge or Chrome over CDP, always with `--mute-audio`. Sixteen runs (`RUNS`, each a `tools/sim.js` plan by its label, read from the sim's source: every ending and Still water variant, Inside boat and sunk, kept, refused once and twice, the knocking, the companion tapped in day, night and red, a seeded later run, one on the test page; `home` fishes its first catch for real so the cast, wait, bite and reel prompts show) at 320x568@2, 375x812@3, 430x932@2 and 1280x800@1, in English and Russian, on the release pages with the test skip on internally. The clock runs `--speed` times faster and stops at every UI moment (a caption, a new prompt, a bubble once its ▾ lights, the Stay word, a panel line once typed, a menu, the lake's whisper, a card once ready, the ocean prompt, the ending once Cast again wakes, the title fresh and after Cast again) while transitions and animations are switched off for the capture. Each snapshot is a PNG plus metrics in `<lang>-<size>/<run>/metrics.json`: per visible box and text its rect, font, the platform fonts that actually drew it (`CSS.getPlatformFontsForNode`, so a fallback glyph shows), overflow, leaving the stage or viewport, overlaps, the canvas grid (columns stage width / W, rows stage height / H) for slab edges and padding (not the bottom padding, which takes the rounding remainder by design), WCAG contrast against its slab in the UI's own colours (`UIRGB`; loose text against its closed outline ring, the picture's mean kept as a note; nothing is judged under the full black fade), the black fade over it, and how many drawn pixels of the boat, the man, the companion, the kept fish, the golden fish and the red eye-sun's disc (`covers-eye`) the panel, card, caption, prompt or bubble cloud hides. `sheets/<run>__<lang>-<size>.png` is a labelled contact sheet per run (red labels have failures); `summary.txt` groups every failure by type and element with example files.
- `npm run itch`: the itch.io upload, English only: `node build.js --itch` writes `tools/out/itch/index.html` (the release page with the title's language link hidden, since the zip has no Russian page) and `tools/itchzip.js` zips it to `itch/still-water.zip` with `index.html` at its root (the zip is gitignored; README has the embed settings).
- `npm run build:test`: writes `tools/out/test.html`, a copy of the game with test mode already on. Publish that file when someone needs to play through the story on a phone without fishing. It is gitignored and must never be uploaded to itch.io.
- `node build.js --lang=ru` (combinable with `--test`; `npm run build:ru` runs both): the Russian page, `tools/out/ru/index.html` and `tools/out/ru/test.html` (gitignored). `--out=<path>` writes anywhere else; `npm run build:site` builds the four published pages into `site/` (gitignored) exactly as the Pages workflow does, so the language links can be tried locally over HTTP.

## Test mode (test build only)
Skips the fishing minigame so the story can be reached in seconds. It exists only in the test build (`npm run build:test`, `tools/out/test.html`): `const TEST_BUILD = false;` in `src/game.js` gates the T and S keys, the Skip button and the `?test` flag in the browser, and `build.js --test` flips it. The shipping `dist/index.html` has no test mode. In the test build it is on from the start, silently, or press T to toggle it (the only time a caption says so: `Test on` / `Test off`, `setTestMode(on, say)`). A small » button (`#skip`, named `Skip`, «Дальше» in Russian) appears in the HUD; each click (or the S key) lands the next fish as if it had been reeled in, including the golden fish and the act 2 red sequence. Dialogue and cinematics still play normally. It lives in `setTestMode` and `testCatch` in `src/game.js`, next to `release()`, and is exported to `tools/`, where the Node tools call it directly.

## Languages (i18n)
One page per language: the language is set by which page you open, never by the browser or a saved choice. `const DEFAULT_LANG = 'en';` in `src/game.js` is baked in by the build (`build.js --lang=ru` flips it, the way `--test` flips `TEST_BUILD`; the plain build stays English), and `pickLang` lets `?lang=ru` or `?lang=en` override it for testing. There is no localStorage language and no `navigator.language`. The four published pages (`.github/workflows/pages.yml`): `/` (English), `/test.html` (English test build), `/ru/` (`--lang=ru`), `/ru/test.html` (`--lang=ru --test`). On the title a small link next to Mute (`#lang`, the same 44 px button on a 15 by 11 game-pixel slab, hidden once play starts) names the other language in two letters (RU on the English page, EN on the Russian one) and goes to its page: `langHref` sends the English page down to `ru/` (or `ru/test.html` from `test.html`) and the Russian page up to `../` (or `../test.html`), relative to `location.pathname`, so it works under `/still-water/` on Pages; under `file://` it names `index.html`, and with a `?lang` override it links to `?lang=<other>` on the same page.

The mechanism: `RU` (in the language section after `RECOUNT`) is keyed by the exact English string, and `tr(s)` returns the Russian in RU mode and `s` otherwise. Text is translated where it reaches the player: `cap` (every caption), `thinkLine` and `dlgBubble` (the bubbles; no bubble carries a label), `dlgRun` (each line copied through `trLine`: text and choice labels; `who` stays English because `fishSpeaking` compares it, and `dlgNext` translates it for the panel), `lakeWhisper`, `showCard` (`cardView`: name, line, voice and `kgText`, a decimal comma in Russian), `composeEnding`, `refreshPrompt` (the urgent style compares against `tr('Tap now')`), the HUD (`countText`, with Russian plurals from `ruPlural`), the endings counters (`foundLine`, the title's `1 of 7 endings` / «1 из 7 концовок»; `foundShort`, the ending card's `1 of 7` beside the pips; `foundText`, `Endings found: 1 of 7`, the pips' accessible name; each one `RU` entry with `{n}` and `{m}` filled by `fillCount`), the Mute name (`UI.muted`), and the template's own text, which `staticText` sets at boot from `STATIC_TEXT` (with `<html lang>`, the tab title and the description; `build.js` also writes them into the page for link previews). Logic never reads translated text: choices pick by closure. Composed text translates its parts before joining: `trJoin` (the sunset caption with `placeWord`, the wish 2 cost line), `recountLine` (each clause through `sentence(tr(...))`), `askedLine` (header and labels), `endingBase` (an `END_BASES` cell built from shared pieces is an array of parts, e.g. `[KNOW_WAY, 'bring', NEW_SHORE]`), `endingExtra`, and `stayBase` (strips `' ' + tr(STAY_DARK)`). The Russian is a literary translation (the golden fish speaks in the feminine, and her question is «Чего тебе надобно, рыбак?»; the Still water ending is «Тихий омут», the game's own Russian name, as the English ending echoes its title; reported speech is quoted with a dash, «…», — сказал он); it was drafted as a table of ids with notes and reviewed, and only the text ships, as `RU`.

To add a string: write it in English where it is used (whole sentences, never an English phrase spliced into another), add `'English': 'Russian'` to `RU`, and make sure it reaches the player through one of the paths above (a new UI text sink must call `tr`). If it is composed, give each piece its own entry and join the translated pieces. Keep English unchanged when you add Russian. `npm run sim` fails if any text the player would see in Russian holds a Latin letter.

## Rules
- The game stays a single HTML file, with no image or audio assets. All art is procedural and all sound is synthesised with WebAudio. The only external request is one Google Fonts stylesheet for one family, Literata (400 to 500 with the optical-size axis, and italic 400), with display=swap and real fallbacks (PT Serif, Georgia, serif); the Latin and Cyrillic subsets load by unicode-range. The title is pixel lettering drawn as SVG (`logoSVG`), not a font.
- Everything is palette-indexed. Add colours as palette indices, never as raw RGB in the render path, so they recolour with the mood.
- Design for mobile first: portrait layout and tap/hold controls. Keep per-pixel work cheap, because `renderTop` and `computeWater` run every frame.
- UI copy is sentence case, short and eerie, in both languages. Every string the player sees has a Russian entry in `RU`.

## Architecture (src/game.js)
The internal resolution is 216 wide by H tall. H ranges from 384 to 470, chosen from the screen aspect, and the image is upscaled with nearest-neighbour. The horizon row is `HY = 236` and the boat waterline is `WL = HY + 6`.

Palette: `buildPalette(mood, dim)` fills `PAL` (RGBA) and `PALRGB`.
- 0–11: the main ramp, blended day, then night, then blood as `WS.mood` goes 0, 1, 2. `dim` darkens it for the Dark ending.
- 12 bobber, 13–16 gold, 17 lantern, 18 fish eye, 19 black, 20 star, 21 red eyes, 22–23 bone, 24 eye glint (the dimmer pair under each pair of eyes), 25 the new shore's dark green (`SHORE_GREEN`). Each mood's values are in `ACC`.
- Sprite strings map characters to indices through `CH`: `0-9 a b` for the ramp, `R d g y w L E K S X` for accents, and `.` for transparent.
- `dith(f, x, y)` turns a continuous shade into an index, using Bayer dithering only near band edges.

Buffers:
- `MOUNT` is generated once in `init`. `CLOUDS` holds two cloud layers (the near cumulus at 3 px/s and the far wisps by the horizon at 1.1 px/s), each a strip `CW = 2W` wide that wraps. `CUMULUS` lists each cloud (layer, centre, flat base, size, bumps); `makeCumulus` builds it as a union of circles with a lifted top row, `cloudField` takes the signed distance to the silhouette (roughened by tiled noise so the strip wraps) and `shadeCloud` lights it: a 2 to 4 px band of index 11 along the upper contour facing the sun, a softer band under it, a mid body, a flat dark base, Bayer dither only at tone edges. `renderTop` samples the layers with a per-layer offset from `cloudT` (which stops while `WS.frozen`), and `KCOR` cuts the fixed sun corridor at sample time so it never drifts with them. Phase 26: `cloudView` (per frame, from `cloudTick`) builds per-layer tables, a source column per screen column (`L.xs`, drift folded in) and a source row base and tile shift per row (`L.rb`, `L.rd`), scaled by 1 / s about (SUNX, HY) with s = lerp(1, `CLOUD_FAR_S` 0.5, `WS.far`), so the clouds shrink with the camera; rows above the strip tile it upward with the period `L.band` (`cloudBand`) and `CLOUD_TILE_DX` per tile (the wisps do not tile); `cloudIdx` reads the same tables. 0.5 keeps the scaled strip within one wrap, so no cloud shows twice in a row. `out_zoom_clouds_strip.png` shows it.
- `TOP` holds the sky, sun, clouds and mountains above the horizon.
- `FRAME` is `TOP` plus the mirrored water.
- `SPR` holds sprites, with 255 meaning transparent.
- `IDX` holds the final indices, and `OUT32` is the RGBA written to the canvas.

Frame order in `render(t)`:
1. Palette.
2. `renderTop`.
3. `topExtras`: stars, birds, cabin and the stalk line.
4. `computeWater`: the mirror with per-row ripple `RIPX`, plus glints.
5. Rings, fish shadows and the eyes (`drawEyes`, in the water, never reflected).
6. Sprites with reflections, via `plotR` and `stampR`.
7. `composite`, which includes the jaw shift.
8. `drawFangs`.
9. `drawUIPix`: the bite marker and the tension bar (`drawTensionBar`: 5 px of fill, the snap zone past `BAR_DANGER` 0.78 shaded index 24 all the time, no tick).
10. RGBA conversion.
11. `applyGlows`: lantern and cabin light.

State:
- `WS` holds the world and mood. Each visual beat is a numeric field, such as `mood`, `sunY`, `sunKind`, `pupil`, `stalk`, `jaw`, `lantern`, `ash`, `companion`, `cabin` (the building; `cabinLit` is its window light, 0 after the still-water dawn, when `CABIN_DARK` is stamped and the glow is off) and `gold`. Animate them with `tween(obj, key, to, dur, ease, done)`; `untween` cancels one. Phase 3 fields: `far` (the ocean camera pull-back, 0 to 1 over `OCEAN_FAR_DUR` 8 s and back to 0; phase 24: `farStep` picks the live group, then `BOAT_ZOOM` (or `SWIM_ZOOM` when swimming), ten silhouettes built at init by `zoomFrame` at `FAR_SCALES` from one canvas of the whole group (min-pooled, so thin lines survive), then the speck; `zoomAnchorX` glides the group’s centre to the horizon centre on the same eased `far`; `farRings` sends a dark `ring` (its `dark` flag shades down, so it reads on the glare) from the waterline every `FAR_RING_GAP` 1.2 s while `far > 0`; `farLive` gates the line and the lantern glow; birds and the sky fish hidden past 0.5; `out_zoom_strip.png` and `out_zoom_swim_strip.png` are eight frames across the pull-back; phase 22: the shoal fades in already in the water (`SHOAL_FADE_IN`) and swims alone after the pull-back; phase 33: the big one is one fish in perspective: `drawBigShadow` maps each column to q along the body from the snout (`b.x`, `b.y` the head end's centre row, `b.t0` its half thickness), the centre line dropping `BIG_DROP` rows over `BIG_LEN` columns on `q ** BIG_BEND` (it hugs the horizon at the head) and the half thickness growing to `BIG_T1`, and `bigShape` gives the plan shape (`bigBodyH`, the forked tail past `BIG_ROOT`, the swept-back dorsal `FIN_D` on the far side and the pectoral `FIN_P` on the near side, `finAt`); `out_ocean_cross_strip.png` is eight frames of it; `CINE_OCEAN` lasts `OCEAN_BIG_T + OCEAN_CROSS`; `scatterFrom` in `updOcean` scatters each small shape as the body reaches it; `bigRise` is the rest state for the shots), `sea` (the open sea, phase 9: the mountains sink and blend into the sky through `mountShift` and `mountIdx`, 0 to 1 over the ocean cutscene and then held at 1 for the rest of the run; every reader of `MOUNT` goes through `mountIdx`, so the sun ring, the stalk, the stars (30 extra ones behind the ridges from `starPass`), the cabin and the jaw composite all tolerate an empty shore; birds hidden while it is above 0.5), `bulge`, `lunge`, `gape`, `gulp`, `streak`, `shed` and `slosh` (phase 25, Swallowed as one lunge: `CINE_SWALLOW` timed by `SW`; `drawHead` classifies each pixel with `headIdx`: the gape wedge (`inGape`, 19), the skull and body (`upperIdx`: `topB` outline, lit rim, `gillIdx`, `finIdx`, the lateral line, the back-to-belly shade), the lower jaw and pale throat (`lowerIdx`, bounded by `underThroat`), and records `HEAD_TOPS`/`HEAD_FOOT` per column; then `drawScales`, `drawHeadEye` (`HEAD_EYE`, gold with a black slit), `drawShed` (sheets off the snout while `shed` > 0), `drawSheet` (the pale water heaped round the speck on the lip), `drawStreaks` (dashes only from the lip tip, chin, underside and one corner drip), `drawCollar` and `drawSlosh` (the water closing); `drawLungeWater` runs after the mirror: the foam collar rows, the reflection broken into rows, and `drawSloshFoam`; `drawLungeSpeck` (`lungeSpeckAt`) draws the speck toward the mouth, rides it on the jaw's lip and slides it into the wedge (`SPECK_TIP`, `SPECK_BIT`); `spray`, three rings and `bigSwimsOff`; phase 33, one fish: the landing ring sits on its head end `MARK_DX` px right of the speck (`oceanMark`, `bigRowAt`); in the lunge `shadowUp` tips it up: `k` to `SHADOW_IN` foreshortens it toward the head end (`bigPose`: length by `k`, drop by `k` squared, the tail paler by `BIG_SINK` in a dithered gradient along it) while `dk` darkens it `BIG_DARK` steps and thickens the head end by `BIG_T0_UP`, so the head breaches out of that spot; `shadowGone` fades it as the head clears, `shadowBack` re-forms it at rest at the rings' row, head end first, and extends the body back, and `bigLeaves` (from `bigSwimsOff`, and `CINE_OCEAN_BACK` when the window is waited out) swims it right along the horizon and `BIG_LEAVE_DY` rows down, fading at its rest size; `out_lunge_shadow_strip.png` is eight frames from settled to swimming off and `out_ocean_wait_strip.png` six of the waited-out departure; `SFX.surge`, `SFX.slam`, `SFX.douse`, and `SFX.weight(false)` only when it swims off; `out_lunge_strip.png` is eight frames across it, `out_lunge_head.png` eight 4x crops of the head). `OCEAN` holds the ocean shoal and the big one (`bigShape`, `bigPose`, `drawBigShadow`); after a waited-out window `spawnSeaShoal` keeps `SEA_SHOAL` giant shapes passing beneath toward the horizon at a slow rate for the rest of the run, at every mood, and `shoalOut` hurries them off with the small shoal. Phase 2 fields: `frozen` (the forever wish via `freezeDay`: cloud time, birds and fish jumps stop, cleared at the still-water dawn), `eyes` (the act 2 look from the water, `eyesLook`, once per run through `G.eyesDone`; reused for one beat in `CINE_DARK`), `farBoat` (the title's far boat after any finished run, stamped into `TOP`). Phase 4, reworked in phase 14: `companionStand`, `leap` and `rock` (the standing frame, the parabola to the disc, the push-off wobble) and `lanternWarm` (the wider glow), Stay only. Phase 6, reworked in phase 9: `boatSunk` (the gold sink, `CINE_SINK`: the hull descends `SINK_PX` over 4 s until the reflecting stamp masks all of it, with bubbles, two rings and one glint; the people do not go with it: `afloat` rides each down only to its float depth, so past `SWIM_AT` the fisherman is a swimmer (`fisherY`: head, shoulders and the rod arm above the waterline, `G.hand` and the rod tip lower), the lantern floats at water level with its glow on the water, the companion sits on the surface at his seat (`compY`, used by `companionHit` too) and the kept fish swims beside the fisherman at full alpha; `reelEnd` and everything else follow `boatLeft`, so casting and the reel work from the water and Still water’s row-out moves the swimmer; the sunk bases of the ending cards (situations 2, 4, 6, 8, 10, 13, 16, 17, 18) say he swims or hangs in the water; Deep's shape from beneath is the swimmer's, `drawSwimmerBeneath`), `dive` (Deep: the horizon rises past the top and the mirror fills the frame) and `glint` (the gold pile's two-frame sparkle). Phase 7: `shoalOut` (set at the cut: the shoal steers to the horizon at full weight, hurries, and `updShadows` removes each shadow as it arrives instead of respawning it). Fishing loop:
- Cast, then nibbles, then a bite after `BITE_WAIT` (1.2 s) plus up to `BITE_WAIT_RND` (2.4 s). The bite window is `BITE_WIN` 1.2 s (`FIRST_BITE_WIN` 1.6 s while `G.tutorial < 1`), or 3.2 s for the golden fish. The prompts (`promptFor`) teach and then step aside: `Tap to cast` and `Wait for a bite` while `G.tutorial < 2`, `Hold to reel. Let go when it pulls.` while `G.tutorial < 3` (catches this session; it is not reset by Cast again), then nothing; the bite prompt `Tap now` always, and the ocean window's `Tap to cast` always. The act 2 golden cast has no bite at all: when its bite time comes, `fishUpdate` starts `redSequence` (no `Tap now`, no way to miss it).
- Hold to reel. Progress rises at `REEL_RATE` (0.42) divided by the species' weight `d`. Tension `reel.T` rises at `PULL_BASE` (0.32), plus `PULL_SURGE` (1.0) during a surge, times `d`, and falls at `RELEASE_EASE` (0.95) on release; surges come every `SURGE_GAP` (1.2 s) plus up to `SURGE_GAP_RND` (1.8 s). These were eased on 2026-09-30 so first-time players land fish faster; with the sim's 0.35 s reaction bot no line snaps and a run averages about 2.4 minutes. The line snaps at 1. A surge is cued (ring, sound, jitter) `SURGE_WARN` (0.25 s) before it pulls: `reel.sAge` counts from its start and the surge term applies only past the warning, so a person can react. Letting go costs `RELEASE_LOSS` (0.06) of progress a second. The golden fish reels at `GOLD_REEL_D` 1.0 under `GOLD_T_CAP` 0.62, so it is heavy but cannot snap, and it lands with no reel-end splash (it surfaces at the left with its own), its reflection calm (`stampR`'s `calm`: whole rows with every `CALM_GAP` 3rd row left out, each shifted by its ripple, one step down the gold ramp by `reflCalm`). The first snap of a run says 'The line snapped. Let go when it pulls.' (`STORY.snaps`).
- When progress `reel.p` reaches 1 the fish lands and a card appears. The card ignores taps for `CARD_GRACE` (0.5 s), and its ▾ marker (`#card::after`, the accent colour) lights after that; its `Tap to continue` is kept for screen readers only. `pickSpecies` never repeats a species whose card already showed this act (`STORY.actSeen`, reset in `startAct`) unless nothing else is left.

Audio: `SFX` synthesises every sound; nothing plays before the first tap, which creates the context (`press`, unlocked again on pointerup, touchend, click and keydown for iOS; suspended while the tab is hidden). The master chain: every voice into `SFX.bus`, then `uw` (the underwater low-pass: `SFX.under(k)`, 20 kHz at 0 to 500 Hz at 1, driven by `WS.dive` in `CINE_DEEP`, set to 1 in the last 0.3 s of Swallowed, reset in `resetAll`), a 30 Hz high-pass, `trim` at `SFX_TRIM` (1.28, the one level knob, before the dynamics), a soft compressor (-20 dB, ratio 3), a limiter at `LIM_TH` (-8.5 dB, ratio 20; with the spec's automatic makeup gain its ceiling is about -3.7 dBFS, so it stays the last level stage) and `out`, the mute (1 or 0), the last node. The play foley (`whoosh`, `plop`, `nibble`, `bite`, `hook`, `reelTick`, `drag`, `slack`, `splash`, `row`, `caught`, `select`, `lap`) goes through `SFX.fol` at `FOLEY_VOL` (0.9, a little under the story sounds, so no plop outranks a climax): each is wrapped after the `SFX` object so its voices route to `SFX.dst`. `tone(f, dur, type, vol, f2, delay, o)` and `noise(dur, vol, type, f, f2, q, delay, o)` start every gain at 0, ramp linearly to `vol` over `o.atk` (default 10 ms, 12 ms under 120 Hz; 30 ms for noise), optionally hold (`o.hold`), decay exponentially and ramp to 0 before the source stops, so nothing clicks; `o.lp` adds a low-pass, `o.pan` a panner, `o.far` the far send (a 0.11 s darkened echo 12 dB down, the knocks across the water), `o.path` moves a noise filter through several points. Noise is a looped 4 s buffer from a random offset, so no long noise runs out. `vr(x, r)` varies plops, splashes, bites, hooks, nibbles, laps, knocks and heartbeats a little each call; it and every other `Math.random` in `SFX` run only with a context, and the game-side sound timers (laps, heartbeat gaps, the reel pawl) use their own stream `arnd`, so the sound never changes the sim. Every low story sound carries upper partials or a 150 to 450 Hz body so it survives a phone speaker (at most 12 LU lost through the renderer's 250 Hz filter): the heartbeat (lub and dub with 2nd, 3rd and 5th partials and a 380 Hz thump), the knock (a 190 Hz body, a lighter 85 Hz door, a 420 Hz panel and a knuckle tick, panned `KNOCK_PAN` toward the cabin with the far echo), the weight, the surge (the octave saw and a rush of water), the slam (a 350 Hz body, a 700 Hz partial and a hit), the rumble (a 7 Hz gated grind) and the drone. The bed (`ambient`, `SFX.scene(mood, sea, frozen, duck)`, sent by `ambientUpdate` only when a value moves more than 0.02): low-passed noise at `AMB_VOL` (0.035, about -35 LUFS momentary in a quiet stretch, so the swells and tolls stand 6 LU or more over it through the phone filter) breathing ±17%, fading in over the row-in, darker at night, half under the red, brighter and quicker at sea, `AMB_FROZEN` (-4 dB) and 220 Hz while the day is frozen; its last argument is a share: `AMB_EYES` (a quarter) while the eyes look (the eyes' sound is that silence), `INSIDE_HUSH` while `G.inside`; laps (`SFX.lap`, a hull clunk sometimes) every 1.8 to 4.5 s by day and 3 to 7 s at night, none in the red, frozen, diving or dark. The red: `SFX.drone` at `DRONE_VOL` through a 520 Hz low-pass whose cutoff breathes ±150 Hz over 20 s and whose level breathes ±20% over 9 s; `SFX.droneDuck(DRONE_DUCK)` steps it back at Stay's impact and when the Inside door shuts, and `DRONE_VOL * INSIDE_HUSH` (0.35, -9 dB) hushes it, the heart (`G.hbVol`) and the bed from the start of `CINE_INSIDE`, so the walk's knocks (`KNOCK_WALK` 0.6, every faint knock keeping a `KNOCK_KNUCKLE` 0.06 tick, the 420 Hz panel at 0.28) stand about 7 LU over the bed through the phone filter; after the door his row and cast are far and small (`row(k)`, `whoosh(k)`, `plop(k)` at `INSIDE_CAST` 0.1), so the three knocks from inside (`KNOCK_INSIDE` 0.4) are the loudest thing in the close. The cast into the ocean window is `OCEAN_CAST` (0.3), under the surge and the slam. The heartbeat (`heartNow`, `heartGap`): `HB_GAP` 1.9 s varied ±4%, in runs of 4 to 7 beats with a 2.5 to 4.5 s rest; Stay quickens it with no rests (the next beat no sooner than a quick gap after the last); `heartStop` stops it for the run (Stay's snap, the Inside door, the Deep dive) and `resetAll` starts it again (`hb`, `hbAt`, `hbVol`, `hbGap`, `hbRun`). `CINE_RED`'s beat at the companion's turn is dropped when the loop beat within `HB_FLAM` (0.5 s), so it never flams. In play: the reel pawl `reelTick(T)` every `REEL_TICK` plus up to `REEL_TICK_RND` (about 6.5 a second, higher with tension); the surge cue is `drag` (a ratchet), not the nibble; `slack` on too early and slipped; `caught(sour)` sours its second note in act 2; `chime(n, red)` through `wishChime` sinks a semitone per granted wish and turns to G, B flat, D, F sharp in the red (the red sky fish); `toll(196)`, then `toll(185)` (each with its octave and the bell's 2.76 partial for a phone), as each step of `sunDrop` begins; `swell(d, glide)` (the sunset glides its G fifth down a semitone; the ocean; Deep); steam `hiss(d, v)` (a band sinking from 4.2 to 2.6 kHz, held, then dying, with a crackle) for the cut and Stay's disc, `snuff` for Dark's lantern, `gurgle` for the gold sink, `glint` for the gold, `snap(far, k)` (the cut's second snap is `snap(true)`, the sky line), `impact` for Stay, `creak(d, door)` (a gated stick-slip; the Inside door is `door`), one far `bird` at a lake dawn. `SFX.weight(on)` is the big one's mass (bible, section 8): two sub-bass oscillators (44 and 52.5 Hz) through a 90 Hz low-pass at 0.6, sines at 88, 132, 176 and 264 Hz, and a looped noise band at 280 Hz groaning on a 0.12 Hz LFO, every pitch sagging 4% over the crossing, the gain ramping linearly from silence to `WEIGHT_VOL` over `OCEAN_CROSS` with no attack, held while it sits under the boat, ducked to `WEIGHT_DUCK` (30%, `SFX.weightDuck`) as the Swallowed head rises (`lungeBulge`) so the surge and the slam stand about 9 to 11 LU over it, and ramped out over `WEIGHT_OUT` (2 s) when it slides off (`CINE_OCEAN_BACK`), when the Swallowed shadow swims off (`bigSwimsOff`), and in `resetAll`. ## Known issues
- Home ending: the jaw composite leaves a horizontal seam mid-screen, which the darkening and fangs mostly hide.
- Upscaling isn't an integer multiple on some screens, so pixel sizes are slightly uneven.
- The keyboard controls (Space/Enter, and 1–6 for choices) are only lightly tested; `domtest` drives one plan through them.
- The build's comment stripping is line-based: a full-line `//` inside a multi-line string or template literal would be dropped. `src/game.js` has none; keep it that way.
- Runtime: the longest path (keep, company, gold, answered, Cut) measures about 3 min 50 s with realistic tap pacing, well under the bible's seven-minute budget; the fishing minigame is most of it and varies by a few tens of seconds with the bite timers.
